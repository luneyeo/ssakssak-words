# DESIGN

AI 에이전트용 디자인 규칙. 어떤 장을 읽을지는 `AGENTS.md`를 따른다.

## 1. 콘셉트와 색상

적용: `src/**/*.tsx`, `src/shared/styles/globals.css`

- 콘셉트: **"싹싹 쓸어 담은 깨끗한 책상"**. 군더더기 없이 깔끔하고, 상쾌하고, 친근한 느낌.
- 여백을 넉넉히 두고, 강조는 민트 한 가지 색으로만 한다. `danger`는 에러에, `warning`은 기다리거나 다시 하면 풀리는 상태(요청 실패, 하루 한도 초과, 요청 몰림)에만 쓴다.
- 색상 값은 `src/shared/styles/globals.css`의 `@theme`이 원본이다. 컴포넌트에서는 **토큰 이름으로만** 쓰고, hex 값을 직접 쓰지 않는다.

| 토큰 | 용도 |
|---|---|
| `bg` | 페이지 배경 |
| `surface` | 카드, 입력 카드 |
| `surface-soft` | 입력창, 언어 선택 배경 |
| `border` | 테두리 |
| `border-soft` | 입력 카드 안의 구분선 |
| `text` | 본문 |
| `text-muted` | 보조 텍스트 |
| `primary` | 버튼, 포인트, 카드 뒷면 배경 |
| `primary-strong` | 칩 글씨, 버튼 hover |
| `primary-soft` | 원문 하이라이트 배경, 칩 배경, 카드 뒷면의 보조 글씨 |
| `danger` | 에러 |
| `warning` | 상태 안내 상자(`StatusNotice`)의 아이콘 (배경·테두리는 투명도를 붙여 쓴다) |
| `warning-soft` | 상태 안내 상자 배경 |
| `warning-strong` | 상태 안내 상자의 설명 글씨 |

## 2. 타이포그래피와 형태

적용: `src/**/*.tsx`, `src/shared/styles/globals.css`

- 폰트: **Pretendard** (한글·영문 공통), 대체 폰트는 `system-ui, sans-serif`
- 본문: 16px / 행간 1.6
- 카드 앞면 단어: 28~32px, bold
- 보조 텍스트: 14px, `text-muted`
- 모서리: 입력 카드 24px, 단어 카드·원문·입력창 16px, 버튼·언어 선택 12px, 칩·배지 9999px
- 그림자: 아주 옅게 (`shadow-sm` 수준), hover 시 한 단계만 진하게
- 간격: 4px 단위 (Tailwind 기본 스케일)

## 3. 레이아웃과 단어 카드

적용: `src/views/**`, `src/widgets/**`, `src/features/**/ui/**`, `src/entities/**/ui/**`

- 모바일 우선, 콘텐츠 최대 너비 `max-w-3xl`, 가운데 정렬
- 카드 그리드: 모바일 1열 → `sm` 2열 → `lg` 3열
- 헤더: 왼쪽에 로고, 오른쪽에 "담은 단어" 링크와 저장한 단어 수 배지(0개면 숨김)
- 담은 단어 페이지: 제목 영역 아래에 언어별 탭(`shared/ui/Tabs`)을 알약 모양으로 둔다. "전체"와 저장한 세트가 있는 언어만, 언어 선택 목록 순서로 보여 주고, 탭 옆 숫자는 저장한 세트 수다. 고른 탭은 `primary` 배경에 흰 글씨, 나머지는 `surface` 배경에 테두리. 저장한 세트가 없으면 탭을 숨기고, 고른 언어의 세트를 모두 지우면 "전체"로 돌아간다.
- 탭은 ARIA 탭 패턴을 따른다. 방향키·Home·End로 옮기면 바로 고르고, Tab 순서에는 고른 탭만 둔다.
- 입력 카드: 위쪽 줄에 언어 선택과 "예시로 해보기" 칩 3개, 가운데 입력창, 아래쪽 줄에 개인정보 안내, 글자 수, 생성 버튼
- 예시 칩을 누르면 입력창에 예시 글을 채우고, 미리 만든 결과를 바로 보여 준다.
- 카드 앞면: 위쪽에 품사 칩과 뒤집기 아이콘, 아래쪽에 단어(`word`)와 기본형(`기본형 {lemma}`, `word`와 다를 때만). 읽는 순서는 단어가 먼저다.
- 카드 뒷면: `primary` 배경에 흰 글씨. 뜻(`meaning`), 원문 문장(`context`, 해당 단어 하이라이트), 예문(`example`)과 번역(`exampleTranslation`)
- 카드 뒤집기: Y축 3D 회전 400ms. `prefers-reduced-motion`이 켜져 있으면 회전 대신 페이드
- 에러는 입력 영역 아래에 `danger` 알림 상자로 보여 주고, 자동으로 사라지게 하지 않는다.
- 단어 없음: 점선 테두리 상자에 아이콘, 제목, 설명, "언어 다시 고르기"(언어 선택으로 포커스)와 "다른 글 넣기"(입력창 전체 선택) 버튼
- 상태 안내 상자(`shared/ui/StatusNotice`): `warning` 상자에 아이콘, 제목, 설명, 버튼. 아래 세 경우에 쓰고, 그 밖에 서버가 보낸 에러는 `danger` 알림 상자를 쓴다.
  - 요청 실패(서버에 닿지 못함): "다시 시도" 버튼(마지막으로 보낸 글로 다시 요청)
  - 요청 몰림(`TOO_MANY_REQUESTS`): "다시 시도" 버튼
  - 하루 한도 초과(`RATE_LIMITED`): 오늘은 다시 시도해도 실패하므로 "다시 시도" 대신 "예시 글로 체험하기" 버튼(첫 번째 예시 글 결과를 API 없이 바로 보여 줌, 입력창은 그대로 둠)

## 4. 문구

적용: 사용자에게 보이는 모든 문구

친근한 존댓말("~해요")을 쓴다.

| 상황 | 문구 |
|---|---|
| 서비스 소개 (제목) | 글 속 단어를 싹싹 쓸어 담아 드려요 |
| 서비스 소개 (설명) | 외국어 글을 붙여넣으면 공부할 단어를 골라, 문맥에 맞는 뜻과 예문을 카드로 만들어 드려요. |
| 언어 선택 | 어떤 언어의 글인가요? |
| 개인정보 안내 | AI가 처리해요. 개인정보가 담긴 글은 넣지 말아 주세요 |
| 생성 버튼 | 단어 싹싹 담기 |
| 예시 영역 | 예시로 해보기 |
| 카드 안내 | 카드를 누르면 문맥 속 뜻이 보여요 |
| 저장 링크 | 담은 단어 / 담은 단어 보러 가기 |
| 언어별 탭 | 전체 / (언어 이름), 탭 목록 이름은 "언어별로 보기" |
| 데모 배지 | 데모 모드 |
| 로딩 | 단어를 싹싹 쓸어 담는 중이에요… |
| 결과 | 단어 {n}개를 싹싹 담았어요! |
| 빈 상태 | 아직 담은 단어가 없어요. 글을 붙여넣어 보세요! |
| 단어 없음 (제목) | 이 글에서는 담을 단어를 찾지 못했어요 |
| 단어 없음 (설명) | 글이 너무 짧거나, 고른 언어와 글의 언어가 다를 수 있어요. 언어를 확인하거나 다른 글을 넣어 보세요. |
| 단어 없음 (버튼) | 언어 다시 고르기 / 다른 글 넣기 |
| 요청 실패 (제목) | 요청을 보내지 못했어요 |
| 요청 실패 (설명) | 인터넷 연결이 끊겼거나 응답이 너무 늦어요. 연결을 확인한 뒤 다시 시도해 주세요. 입력한 글은 그대로 남아 있어요. |
| 요청 실패 (버튼) | 다시 시도 |
| 하루 한도 초과 (서버 문구) | 오늘 담을 수 있는 양을 다 썼어요. 예시 글로 체험해 보세요! |
| 하루 한도 초과 (제목) | 오늘 담을 수 있는 양을 다 썼어요 |
| 하루 한도 초과 (설명) | 하루에 담을 수 있는 양이 정해져 있어요. 내일 다시 담을 수 있고, 그동안은 미리 만든 예시 글로 체험해 볼 수 있어요. |
| 하루 한도 초과 (버튼) | 예시 글로 체험하기 |
| 요청이 몰림 (서버 문구) | 요청이 너무 많아요. 잠시 후 다시 시도해 주세요 |
| 요청이 몰림 (제목) | 요청이 너무 많아요 |
| 요청이 몰림 (설명) | 지금 단어를 담으려는 사람이 많아요. 잠시 후 다시 시도해 주세요. 입력한 글은 그대로 남아 있어요. |
| 요청이 몰림 (버튼) | 다시 시도 |
| 에러 | 앗, 단어를 담지 못했어요. 잠시 후 다시 시도해 주세요 |

## 5. 접근성

적용: `src/**/*.tsx`

- 카드는 `<button>`으로 만들고, Enter와 Space로 뒤집을 수 있어야 한다.
- 뒤집힌 상태를 `aria-pressed` 또는 `aria-label`로 알린다.
- 모든 인터랙션 요소에 눈에 보이는 focus 스타일(`primary` 링)을 준다. 링은 `globals.css`의 전역 `:focus-visible` 규칙이 맡으므로 컴포넌트마다 클래스를 붙이지 않는다.
- 전역 링과 다르게 해야 할 때만 컴포넌트에서 덮어쓴다. 예: 원문에서 이동해 온 카드는 마우스 사용자에게도 보이도록 `focus:` 링을 쓰고, 포커스만 옮겨 두는 제목은 `outline-none`을 쓴다.
- 텍스트 대비는 WCAG AA 이상을 지킨다. `primary` 위 흰 글씨는 대비가 약 5.5:1이라 작은 글씨에도 쓸 수 있다. `primary` 위 보조 글씨는 흰색의 투명도를 낮추면 AA에 못 미치므로 `primary-soft`를 쓴다.
