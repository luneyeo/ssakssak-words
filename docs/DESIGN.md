# DESIGN

AI 에이전트용 디자인 규칙. 어떤 장을 읽을지는 `AGENTS.md`를 따른다.

## 1. 콘셉트와 색상

적용: `src/**/*.tsx`, `src/app/globals.css`

- 콘셉트: **"싹싹 쓸어 담은 깨끗한 책상"**. 군더더기 없이 깔끔하고, 상쾌하고, 친근한 느낌.
- 여백을 넉넉히 두고, 강조는 민트 한 가지 색으로만 한다.
- 색상 값은 `src/app/globals.css`의 `@theme`이 원본이다. 컴포넌트에서는 **토큰 이름으로만** 쓰고, hex 값을 직접 쓰지 않는다.

| 토큰 | 용도 |
|---|---|
| `bg` | 페이지 배경 |
| `surface` | 카드, 입력창 |
| `border` | 테두리, 구분선 |
| `text` | 본문 |
| `text-muted` | 보조 텍스트 |
| `primary` | 버튼, 포인트 |
| `primary-strong` | 흰 배경 위 강조 텍스트, 버튼 hover |
| `primary-soft` | 원문 하이라이트 배경, 칩 배경 |
| `danger` | 에러 |

## 2. 타이포그래피와 형태

적용: `src/**/*.tsx`, `src/app/globals.css`

- 폰트: **Pretendard** (한글·영문 공통), 대체 폰트는 `system-ui, sans-serif`
- 본문: 16px / 행간 1.6
- 카드 앞면 단어: 28~32px, bold
- 보조 텍스트: 14px, `text-muted`
- 모서리: 카드 16px, 버튼·입력창 12px, 칩·배지 9999px
- 그림자: 아주 옅게 (`shadow-sm` 수준), hover 시 한 단계만 진하게
- 간격: 4px 단위 (Tailwind 기본 스케일)

## 3. 레이아웃과 단어 카드

적용: `src/app/**/*.tsx`, `src/features/word-card/components/**`

- 모바일 우선, 콘텐츠 최대 너비 `max-w-3xl`, 가운데 정렬
- 카드 그리드: 모바일 1열 → `sm` 2열 → `lg` 3열
- 입력 영역 아래에 "예시 글로 체험하기" 버튼 3개를 칩 형태로 배치한다.
- 카드 앞면: 단어(`word`), 기본형(`lemma`, `word`와 다를 때만), 품사 칩
- 카드 뒷면: 뜻(`meaning`), 원문 문장(`context`, 해당 단어 하이라이트), 예문(`example`)과 번역(`exampleTranslation`)
- 카드 뒤집기: Y축 3D 회전 400ms. `prefers-reduced-motion`이 켜져 있으면 회전 대신 페이드

## 4. 문구

적용: 사용자에게 보이는 모든 문구

친근한 존댓말("~해요")을 쓴다.

| 상황 | 문구 |
|---|---|
| 서비스 소개 | 글 속 단어를 싹싹 쓸어 담아 드려요 |
| 생성 버튼 | 단어 싹싹 담기 |
| 예시 영역 | 예시 글로 먼저 체험해 보세요 |
| 데모 배지 | 데모 모드 |
| 로딩 | 단어를 싹싹 쓸어 담는 중이에요… |
| 결과 | 단어 {n}개를 싹싹 담았어요! |
| 빈 상태 | 아직 담은 단어가 없어요. 글을 붙여넣어 보세요! |
| 단어 없음 | 이 글에서는 담을 단어를 찾지 못했어요 |
| 하루 한도 초과 | 오늘 담을 수 있는 양을 다 썼어요. 예시 글로 체험해 보세요! |
| 요청이 몰림 | 요청이 너무 많아요. 잠시 후 다시 시도해 주세요 |
| 에러 | 앗, 단어를 담지 못했어요. 잠시 후 다시 시도해 주세요 |

## 5. 접근성

적용: `src/**/*.tsx`

- 카드는 `<button>`으로 만들고, Enter와 Space로 뒤집을 수 있어야 한다.
- 뒤집힌 상태를 `aria-pressed` 또는 `aria-label`로 알린다.
- 모든 인터랙션 요소에 눈에 보이는 focus 스타일(`primary` 링)을 준다.
- 텍스트 대비는 WCAG AA 이상을 지킨다. `primary` 위의 흰 글씨는 굵은 큰 글씨에만 쓰고, 작은 글씨는 `primary-strong`을 쓴다.
